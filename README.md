# Treasure Hunt hra

Unity version: `6000.6.5f1`.

Minimum Android verzia: `12`.

### Nastavenie projektu
Na https://cloud.maptiler.com/ si vytvorte účet a v sekcii `API Keys` vytvorte svoj API kľúč. Tento kľúč uložte do súboru `MapTilerKey.txt` v `Assets/Resources`.

Po prvom spustení hry na mobile ju hneď zavrite a v nastaveniach povolte prístup ku kamere a <ins>**presnej**</ins> polohe. Potom ju spustite znova. Ak toto nemáte správne nastavené tak hra crashne.
